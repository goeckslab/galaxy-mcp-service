# Security reports

Please report suspected vulnerabilities in the Galaxy MCP service privately through the [support contact form](https://mcp.galaxymcp.org/support#private-contact). Include the affected endpoint or feature, expected and observed behavior, and a minimal reproduction if possible. Redact API keys, OAuth tokens, passwords, private datasets, and personal information from reports and logs.

Do not open a public GitHub issue for a security report. We will use the reply address you provide to follow up and coordinate a fix and disclosure. For urgent account protection, revoke the affected API key in your Galaxy account.
